Lithium BMS CAN Interface

Project Overview

  • Situation: Required a portable display module for a Lithium Battery Management System.
  • Task: Design a PCBA to interface directly via CAN network.
  • Action: Modeled the 3D PCB in KiCad and exported an Interactive BoM for assembly validation.
  • Result: Created a highly robust, portable diagnostic visualization tool.
