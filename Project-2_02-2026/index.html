Lithium BMS CAN Interface

Project Overview

  • Situation: Required a portable display module for a Lithium ION batteries.
  • Task: Design a prototype PCB to interface directly with the battery BMS via CAN network.
  • Action: Modeled the 3D PCB in KiCad and exported an Interactive BoM for assembly validation.
  • Result: Created a portable diagnostic visualization tool.
